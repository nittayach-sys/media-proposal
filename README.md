# Media Package Generator — AI Level 4

แอป Streamlit ที่ให้ AI อ่านบรีฟลูกค้า → เลือกสื่อจากเรทการ์ด → คำนวณงบ → เขียน Sales Activity ภาษาไทย → export Excel
โดย **คนเป็นผู้ตรวจและอนุมัติทุกขั้น** AI ไม่เขียนลงแพ็กเกจหรือไฟล์ export เองโดยไม่มีการกดของคน

> "AI Level 4" ในที่นี้เป็นนิยามที่ตกลงกันในแชท (ไฟล์ Sales Sidekick ไม่ได้ระบุเกณฑ์ AI Level)
> ถ้าบริษัทมีนิยาม Level 1–4 อย่างเป็นทางการ ส่งมาเพื่อปรับให้ตรงได้

## ไฟล์ที่ต้องอยู่ใน GitHub repo (โฟลเดอร์เดียวกัน)
- `app.py`
- `media_database.csv`
- `requirements.txt`  (เพิ่ม `anthropic`)

ลบ `template.xlsx` ออกจาก repo ได้ เพราะเวอร์ชันนี้ไม่ใช้แล้ว
ต้องอัปโหลด `app.py`, `media_database.csv` และ `requirements.txt` พร้อมกัน ถ้าอัปไม่ครบแอปจะ error

## ตั้งค่า Secrets (ต้องทำก่อนใช้ปุ่ม AI)
ใน Streamlit Community Cloud: เปิดแอป → Manage app → ⋮ → Settings → Secrets แล้วใส่

```toml
ANTHROPIC_API_KEY = "sk-ant-..."     # key ของคุณเอง ห้ามใส่ใน GitHub หรือส่งในแชท
APP_PASSWORD = "ตั้งรหัสผ่านที่เดายาก"   # จำเป็น: ลิงก์แอปฟรีเป็นสาธารณะ
# ไม่บังคับ
# ANTHROPIC_MODEL = "claude-sonnet-5-5"
# MAX_AI_CALLS = 10                   # จำนวนครั้งเรียก AI ต่อ session
```

- ถ้าไม่ตั้ง `APP_PASSWORD` ปุ่ม AI จะไม่ทำงาน เพื่อกันคนนอกใช้ API key ของคุณ
  (ข้ามได้ด้วย `ALLOW_OPEN_ACCESS = "true"` แต่ไม่แนะนำ)
- ถ้าตั้ง `APP_PASSWORD` ทั้งแอปจะถามรหัสผ่านก่อนเข้าใช้งาน

## AI ทำงานอย่างไร
1. **AI เลือกสื่อ** — ส่งบรีฟ + งบ + รายการสื่อทั้งหมด (152 รายการ) ให้ Claude เลือกเป็น id พร้อมจำนวนเดือนและเหตุผล
   แอปตรวจผลก่อนแสดง: ตัด id ที่ไม่มีจริง/ซ้ำ และปรับเดือนให้อยู่ใน 1–24
2. **คนอนุมัติ** — ติ๊กเลือก/แก้เดือน แล้วกดอนุมัติ จึงเข้าแพ็กเกจ
3. **AI เขียน Sales Activity** — จากแพ็กเกจที่อนุมัติแล้ว + บรีฟ + ข้อมูลยืนยันที่คุณพิมพ์เพิ่ม
   เป็นย่อหน้าภาษาไทยเดียว ครอบคลุม 5 องค์ประกอบตามเกณฑ์ (Call/Email หรือ Meeting/Roadshow, Stage 1/2)

### กติกาความถูกต้องของ Sales Activity
- ห้ามแต่ง feedback, สถานการณ์, insight, งบ, วันนัด, คู่แข่ง — ถ้าไม่มีหลักฐานจะขึ้น `[รอข้อมูล: …]` ให้เติมเอง
- Next Step ที่ไม่มีหลักฐานจะขึ้นต้นด้วย "ขั้นต่อไปควร…" และระบุในตารางว่าเป็นข้อเสนอแนะ
- ตารางผลตรวจแสดง **ความครบของข้อ** เท่านั้น ไม่ใช่คะแนน Good/Average/Bad
  (ไฟล์เกณฑ์ไม่ได้ระบุวิธีให้คะแนนต่อข้อ จึงไม่ให้ระบบเดาคะแนน)
- Stage 3 Close Deal (Win/Lost) ยังไม่รวมในเวอร์ชันนี้

## ข้อมูลที่ยังต้องยืนยัน
1. **ระยะเวลา Create ใน Salesforce** — ไฟล์ Sales Sidekick หน้า 3 (Direct team 2026) ระบุไม่เกิน **7 วัน**
   ส่วนเกณฑ์ planb-kpi (1-PlanB) ระบุไม่เกิน **10 วัน** แอปให้เลือกได้ ค่าเริ่มต้นคือ 7 วัน (เข้มกว่า)
2. **ไฟล์ "Changan"** — ยังไม่เคยได้รับ layout ของ Excel จึงยังเป็นแบบชั่วคราวตามรายชื่อคอลัมน์ที่ระบุ
3. **Tax 3 (Q1–Q4)** — ไฟล์เรทการ์ดไม่มีคอลัมน์ภาษีรายไตรมาส ตอนนี้เลือกไตรมาสต่อรายการ (ภาษี 3% ของค่าผลิต Static ลงไตรมาสเดียว)
4. **สื่อ 16 ชีท** (BTS Cityline, BTS MAX, BTS Station ฯลฯ) ยังไม่อยู่ในฐานข้อมูล AI จึงยังไม่เสนอสื่อกลุ่มนี้
   เพิ่มได้โดยเติมแถวใน `media_database.csv` ตามคอลัมน์เดิม

## ข้อมูลที่ถูกส่งออกไปเมื่อกดปุ่ม AI
ข้อความบรีฟ ข้อมูลยืนยันที่พิมพ์ รายการสื่อและราคา Agency Rate/ค่าผลิตทั้งหมดในฐานข้อมูล จะถูกส่งไปยัง Anthropic API
ตรวจสอบนโยบายข้อมูลของบริษัทก่อนใช้กับบรีฟหรือราคาที่เป็นความลับ
